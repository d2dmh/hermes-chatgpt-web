## 0. 硬约束（先读，违反即停止）

1. **不要**动用户自己的浏览器或它的配置目录，只在独立 profile 上操作。
2. **不要**索取、输入或回显任何密码、验证码、令牌、密钥。**<配对码> 是唯一允许输入浏览器的凭据**，
   它由本机命令生成、一次性、几分钟内过期。
3. **不要**用「把文件内容粘贴进聊天」的方式验证读取成功。验证必须是它自己读到、且与本机逐字符一致。
4. **不要**覆盖工作区里已有的文件；导入素材只使用全新路径。
5. 有两步**必须交给人工**：<登录 / 授权确认>。不要代劳，也不要尝试猜测凭据。
6. 任何写入、删除、安装、升级操作前，先向用户说明范围并取得同意。
